# Type-Fast
A fun typing test!
 - 3 different difficulties to choose from: Easy, Medium, and Hard!
 - Different difficulties change the goals of the WPM and Accuracy!
        
        Try to hit the Word Per Minute range!
        Try to get over the given Accuracy!
        
 - 2 Different modes: Phrases and Words!
        
        Phrases - Picks a random phrases out of a list of options!
        Words - Combines 10 random words into a sentence!

 - Choose from 4 different themes! 

        Dark - Classic dark mode styles
        Light - Classic light mode styles
        Grass - A grassy themed UI and background!
        Terra - A cozy tan theme!

Make sure you let all the assets load in!
